# アセンブリ言語仕様

> p8080 の**アセンブリ言語リファレンス**です。`.asm` に書ける構文をまとめています。CLI は [cli.md](cli.md)、Python API は [python-api.md](python-api.md) を参照してください。

## 基本構文

ニーモニック・レジスタ名・疑似命令は大文字・小文字を区別しません。`;` 以降はコメントとして扱います。

```asm
ORG 0x0100      ; 開始アドレス設定
mvi a, 0x10     ; 16進数
mvi b, 10       ; 10進数
mvi c, 0b1010   ; 2進数
mvi d, 0o17     ; 8進数
lxi h, 'AB'     ; 文字リテラル (0x4142)
mvi a, -1       ; 負数（0xFF に変換）
```

## 命令の書き方（Intel 表記）

命令は Intel の 8080 マニュアル（*Intel 8080 Microcomputer Systems User's Manual*）の表記で書きます。

* **レジスタ**は `A` `B` `C` `D` `E` `H` `L`。**`M` は HL が指すメモリ**で、レジスタと同じ位置に書けます（`MOV A, M` / `MVI M, 0` / `INR M`）。
* **レジスタ対**は先頭のレジスタ名で書きます。`B` が BC、`D` が DE、`H` が HL です。ほかに `SP`（スタックポインタ）と、`PUSH` / `POP` 専用の `PSW`（A とフラグ）があります。
* **条件はニーモニックの一部**です。`JNZ` / `JZ` / `JNC` / `JC` / `JPO` / `JPE` / `JP` / `JM`、コールは `C` で始まり（`CNZ` など）、リターンは `R` で始まります（`RNZ` など）。
* **`RST` のオペランドは番号**（`0`〜`7`）で、飛び先は番号 × 8 です。`RST 7` は `0x0038` へ飛びます。

```asm
    org 0x0000
    MOV  A, M       ; 7E  HL が指すメモリを A へ
    MVI  M, 0       ; 36 00
    LXI  H, 0x2000  ; 21 00 20
    LDA  0x2000     ; 3A 00 20  アドレスから A を読む
    STA  0x2001     ; 32 01 20  A をアドレスへ書く
    PUSH PSW        ; F5
    JNZ  0x0000     ; C2 00 00
    RST  7          ; FF  0x0038 を呼ぶ
```

> **`JP` と `CP` は Z80 と意味が違います。** 8080 の `JP` は「正（positive）なら飛ぶ」条件付きジャンプ（`F2`）、`CP` は「正なら呼ぶ」コール（`F4`）です。無条件ジャンプは `JMP`、比較は `CMP` / `CPI` です。Z80 の表記（`LD` / `JP (HL)` / `DJNZ` など）は未知の命令としてエラーになるので、Z80 向けのソースをそのまま組むと気づけますが、`JP` と `CP` だけは綴りが通ってしまい、別の命令になります。

8080 の命令に**メモリ参照の括弧はありません**（メモリは `M` か、`LDA` / `STA` のような専用の命令で表します）。そのため、オペランドの `(` はいつも**式の括弧**です（[式の評価](#式の評価)）。

```asm
    MVI  A, (1 + 2) * 3     ; 3E 09
    LDA  (TABLE + 1)        ; LDA TABLE+1 と同じ
```

未定義の 12 のオペコード（`08` `10` `18` `20` `28` `30` `38` `CB` `D9` `DD` `ED` `FD`）は命令として書けません。逆アセンブルすると `db` として出ます。

## 数値リテラル

数値は Python の整数リテラル形式で記述します。

| 記法       | 例          | 説明          |
| -------- | ---------- | ----------- |
| 10進数     | `42`       | 接頭辞なし       |
| 16進数     | `0x2A`     | `0x` 接頭辞    |
| 2進数      | `0b101010` | `0b` 接頭辞    |
| 8進数      | `0o52`     | `0o` 接頭辞    |
| 文字リテラル   | `'A'` `'AB'` | 1〜2文字。2文字は上位=1文字目・下位=2文字目（`'AB'` → `0x4142`） |

* **負数**も指定できます。バイトオペランドは `-128`〜`255`、ワードオペランドは `-32768`〜`65535` の範囲で、内部で2の補数に変換されます（例: `db -1` → `0xFF`）。
* 文字リテラルは式の中でも使用できます（例: `db 'A' + 1`、`dw 'A' * 0x100`）。

> **Intel 流の数値表記（`0FFH` / `377Q` / `1010B`）や、他のアセンブラの記法（`$0A` / `#0A` / `%1010`）は使えません。** `$` は現在アドレス、`%` は剰余演算子です。8080 の既存のソースは `0FFH` の形で書かれていることが多いので、アセンブルの前に数値の表記を変換してください。Python から使う場合は、その変換をアセンブルの前段に挟めます（「[複数チャンクの連結アセンブル](python-api.md#複数チャンクの連結アセンブル)」）。

## 疑似命令

| 命令        | 説明               | 例                    |
| --------- | ---------------- | -------------------- |
| ORG       | アドレス指定           | ORG 0x8000           |
| EQU       | 定数定義             | VAL: EQU 0xFF        |
| DB / DEFB | バイトデータ定義         | db 1, 2, "String", 0 |
| DW / DEFW | ワードデータ定義         | dw 0x1234, LABEL     |
| DS / DEFS | 指定バイト数をfill値で埋める | ds 16, 0xFF          |
| ALIGN     | 次の境界までfill値で埋める   | align 16, 0xFF       |
| END       | アセンブル終了（以降の行を無視） | end                  |
| IF / ELSEIF / ELSE / ENDIF | 条件アセンブル | IF DEBUG ... ENDIF |

> **`INCLUDE` / `INCBIN` / `MACRO` / `REPT` はありません。** 同じことは Python 側で書きます（「[複数チャンクの連結アセンブル](python-api.md#複数チャンクの連結アセンブル)」）。この場合、`.asm` ファイル単体ではビルドできず、Python の記述が必要になります。

**EQU の制約:** 定義値は `0`〜`65535` の範囲です。右辺では**定義済みの EQU 定数を参照できます**（後方参照）。前方参照とラベル参照はできません。

```asm
WIDTH:  EQU 8
HEIGHT: EQU 8
SIZE:   EQU 8 * 8           ; OK（数値リテラルと算術式）
AREA:   EQU WIDTH * HEIGHT  ; OK（定義済み EQU の参照）
BIG:    EQU AREA > 32       ; OK（比較演算子も使える）

AHEAD:  EQU LATER * 2       ; NG（前方参照）
LATER:  EQU 8
ADDR:   EQU DRAW_ROW        ; NG（ラベルのアドレスは参照不可）
```

**`DS` と `ALIGN` もラベルを参照できません。** 定数・定義済みの `EQU`・`$` は使えます。

```asm
SIZE: EQU 16

ds SIZE             ; OK（定義済み EQU）
ds 16 - ($ & 0x0F)  ; OK（$ はラベルではない）
align SIZE          ; OK

ds TABLE_END        ; NG（ラベル参照）
align TABLE_END     ; NG
```

`DB` / `DW` にはラベルを書けます（`dw LABEL`）。

### 境界揃え (ALIGN)

`ALIGN n` は現在アドレスを次の n バイト境界まで進めます。既に境界上なら何もしません。

```asm
ORG   0x0100
db    1, 2, 3
ALIGN 16          ; 0x0103 から 0x0110 まで 0 で埋める
TBL:  db 0xAA     ; TBL = 0x0110
```

2 つ目のオペランドで埋める値を指定できます。`DS` と同じで、既定は `0` です。

```asm
ALIGN 256, 0xFF
```

**境界は 2 の冪に限ります。** `ALIGN 10` はエラーです。

境界は ORG からの相対ではなく**絶対アドレス**に対して取ります。`$` と同じ基準なので、`ds 16 - ($ & 0x0F)` と書く代わりに `align 16` と書けます。

### 条件アセンブル (IF / ELSEIF / ELSE / ENDIF)

条件が偽のブロックは、アセンブル結果に一切含まれません。ラベル定義も ORG も無効になります。

```asm
IF DEBUG
    LXI D, MSG_DEBUG
ELSE
    LXI D, MSG_NORMAL
ENDIF
```

枝が 3 つ以上になるときは `ELSEIF` を使います。`ELSE` と同じく省略できます。

```asm
IF      VERSION == 1
    LXI D, TABLE_V1
ELSEIF  VERSION == 2
    LXI D, TABLE_V2
ELSE
    LXI D, TABLE_DEFAULT
ENDIF
```

採用されるのは**最初に条件が真になった枝だけ**です。それより後ろの `ELSEIF` は条件式を評価しません。`ELSE` より後ろには書けません。

フラグは `-D` でコマンドラインから渡します。複数指定した場合は左から順にマージされます（同じキーは後勝ち）。

```bash
p8080 asm -f main.asm -o rom.bin -D DEBUG=1
p8080 asm -f main.asm -o rom.bin -D DEBUG=1 -D TRACE=0
p8080 asm -f main.asm -o rom.bin -D DEBUG            # 値を省略すると 1
```

値は `0x` / `0b` 表記も使えます（`-D ADDR=0x8000`）。

多数まとめて渡すときは Python の辞書リテラルも使えます。ただし `{`・`}`・空白をシェルが解釈するため、**引用符で囲む必要があります**。

```bash
p8080 asm -f main.asm -o rom.bin -D '{"DEBUG": 1, "TRACE": 0}'   # bash
p8080 asm -f main.asm -o rom.bin -D "{'DEBUG': 1, 'TRACE': 0}"   # cmd
```

> 引用符を付けずに `-D {"A":1,"B":2}` と書くとシェルのブレース展開が働き、まったく別の引数に化けます。手打ちでは `NAME=VALUE` 形式を使ってください。

`-D` で渡した値は、ソース先頭に `DEBUG: EQU 1` を書いたのと同じ扱いになります。辞書リテラルは `ast.literal_eval` で解釈するため、コードは実行されません。値は整数のみです。

**条件式の制約:**

条件で参照できるのは、定義済みの `EQU` 定数だけです。

```asm
VAL: EQU 8
IF VAL          ; OK（定義済み EQU）
IF DRAW_ROW     ; NG（ラベルのアドレスは未確定）
IF UNDEFINED    ; NG（未定義シンボルはエラー。IFDEF は用意していません）
```

条件式には比較演算子・論理演算子が使えます（[式の評価](#式の評価)を参照）。

```asm
IF DEBUG                  ; 0 以外が真
IF VAL == 8
IF VAL > 4 && !DEBUG
IF FLAGS & 0x04
```

到達しない枝の中の条件式は評価されないため、無効ブロック内で未定義シンボルを参照してもエラーにはなりません。

## ラベル

`:` で終わる識別子をラベルとして定義できます。行頭にも、命令の前にも書けます。**ラベルは大文字・小文字を区別します**。`Start` と `START` は別のラベルになります（大小文字を区別しない `EQU` 定数とは扱いが違います）。

**ラベルの命名規則:**

* 先頭文字: 英字 (`A-Z`, `a-z`) または `@`
* 2文字目以降: 空白・`;`・演算子と区切りの記号（`,` `(` `)` `:` など）以外なら使える。英数字・`_`・`.` など
* 予約語（レジスタ名・ニーモニック・疑似命令名）は使用不可

```asm
LOOP:      dcr b       ; OK
SUB_01:    ret         ; OK (_は2文字目以降に使用可)
@START:    nop         ; OK (@ で始まるラベル)
_LABEL:    nop         ; NG (先頭が _ は不可)
M:         nop         ; NG (予約語: レジスタ名。M は HL が指すメモリ)
SUB:       nop         ; NG (予約語: 8080 の減算命令)
ORG:       nop         ; NG (予約語: 疑似命令名)

LOOP: dcr b
   jnz LOOP
```

> **1 文字のレジスタ名（`B` / `C` / `D` / `E` / `H` / `L` / `M`）と、8080 のニーモニック（`SUB` / `CALL` / `CP` / `IN` / `OUT` など）はラベルに使えません。** Z80 のソースでは使えた名前（`SUB` は Z80 にもありますが、`CP`・`JP`・`RP` のような短い名前）が、8080 では予約語にぶつかることがあります。

> **ローカルラベル（`.loop` のようにスコープを持つラベル）はありません。** 予約語とぶつかる名前や、プログラムで生成した名前には `@` を使ってください（`@M`、`@gen_0`）。`_` で始まる名前を使う他のアセンブラ向けのソースは、アセンブルの前段で改名してください（「[複数チャンクの連結アセンブル](python-api.md#複数チャンクの連結アセンブル)」）。

## 式の評価

オペランドには数式を記述できます。演算子の優先順位はC言語準拠です（上ほど優先順位が低い）。

| 演算子                    | 説明        |
| ---------------------- | --------- |
| `\|\|`                  | 論理OR      |
| `&&`                   | 論理AND     |
| `\|`                    | ビットOR     |
| `^`                    | ビットXOR    |
| `&`                    | ビットAND    |
| `==` `!=`              | 等価比較      |
| `<` `<=` `>` `>=`      | 大小比較      |
| `<<` `>>`              | 左/右シフト    |
| `+` `-`                | 加減算       |
| `*` `/` `%`            | 乗除算・剰余    |

* `/` は**整数除算（切り捨て）**です（例: `7 / 2` → `3`）。ゼロ除算はアセンブルエラーになります。
* 比較演算子と論理演算子は **0 か 1** を返します。0 以外がすべて真です。
* 単項演算子として `-`（負号）・`~`（ビットNOT）・`!`（論理NOT）が使用できます。`~` と `!` は別物で、`~0` は `-1`、`!0` は `1` です。
* 論理演算子は定数式なので**短絡評価しません**（右辺も必ず評価されます）。
* 括弧 `()` で優先順位を明示できます。`$` は現在のアセンブルアドレス（PC）を表します。

```asm
lda TABLE + 1
dw END_ADDR - START_ADDR
mvi a, 0xFF & ~0x80   ; ビット7をクリア
dw TABLE >> 8         ; 上位バイトを取り出す
jmp $                 ; 無限ループ（$ は JMP 命令自身のアドレス）
db $ - START          ; START からのバイト数を埋め込む
ds 16 - ($ & 0x0F)    ; 16バイト境界まで埋める（align 16 と同じ）
db SIZE > 0x100       ; 比較結果は 0 か 1
```

比較・論理演算子は、条件アセンブルでよく使います。

```asm
IF  VERSION == 2 && !DEBUG
    ...
ENDIF
```
